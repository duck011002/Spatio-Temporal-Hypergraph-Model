# 规则教师固定参数消融结果

## 1. 消融协议

本次消融完全在本地 CPU 上运行，不重新加载 checkpoint，不重新执行随机邻居采样，也不调用 LLM。

为避免观察 test 后继续调参，实验固定：

- validation 与 test 的 Top-20 候选缓存；
- 三个数据集已经冻结的完整教师权重；
- NYC、CA、TKY 的规则强度分别为 0.50、0.25、0.20；
- 所有规则统计仍只来自各数据集的训练事件。

消融包含：

- 五个单规则版本；
- 逐项移除一个规则；
- 用户偏好与空间、时间的累加组合；
- 完整规则教师；
- 在 validation 上扫描 `lambda=0.00, 0.05, ..., 1.00`。

单规则和移除规则实验都保持原数据集的冻结 `lambda`，不为每个变体重新搜索超参数。这是受控贡献分析，不以 test 结果重新选择最终配置。

所有消融变体的 Recall@20 都与对应配对基线严格相同，证明实验只改变 Top-20 内部排序。

观察：

- 在冻结的 `lambda=0.50` 下，空间、时间和用户偏好单独使用都降低 Recall@1；三项组合后则新增 23 个 Top-1 命中。这是明确的规则协同，而不是单条启发式规则主导。
- 移除时间后 Recall@1 低于基线 7 个样本，说明时间规则对于头部命中不可缺少。
- 移除空间或用户偏好后仍有正收益，但明显低于完整组合，说明两者提供互补信息。
- 类别转移与热度的冻结权重只有 0.02083 和 0.01157。移除二者在 test 上没有造成稳定损失。

需要保持边界：用户偏好、空间与时间三项版本在 test 上略高于当前完整教师，但完整教师在 validation 的选择目标仍略高，不能根据已经观察到的 test 将正式配置改成三规则版本。

## 5. TKY R0

TKY 的完整教师权重为：

```text
user_preference = 1.0
spatial = temporal = category_transition = popularity = 0.0
lambda = 0.20
```

因此，完整教师、仅用户偏好、移除任一零权重规则的结果完全一致：

- Recall@1 增加 0.0022733731，即 16 个命中。
- Recall@5 增加 0.0017050298，即 12 个命中。
- Recall@10 增加 0.0014208582，即 10 个命中。
- MRR 增加 0.0033076964。

其他规则单独使用时：

- 仅空间损失 67 个 Top-1 命中，但增加 13 个 Top-5 和 33 个 Top-10 命中。
- 仅时间损失 1、38、38 个 Top-1、Top-5、Top-10 命中。
- 仅类别转移损失 14、34、45 个对应命中。
- 仅热度增加 12 个 Top-1 命中，但损失 45 个 Top-5 与 20 个 Top-10 命中，MRR 略降。

观察：TKY 当前收益完全由用户长期偏好提供。空间规则仍呈现“牺牲首位、改善较后位置”的倾向，但在当前选择目标下不值得启用。

不能据此声明 TKY 没有时空规律。合理结论是：在当前 R0 候选、规则定义和验证目标下，显式时空规则没有提供超出主模型的稳定增量。

## 6. Lambda 敏感性

| 数据集与骨干 | 冻结 lambda | Validation 目标值 | lambda=0 目标值 | lambda=1 目标值 |
|---|---:|---:|---:|---:|
| NYC A4 | 0.50 | 2.3966308618 | 2.3146533302 | 2.1228709086 |
| CA R0 | 0.25 | 1.7978560729 | 1.7637238533 | 1.4197644312 |
| TKY R0 | 0.20 | 2.0463884616 | 2.0215764668 | 1.6546445890 |

三个冻结 `lambda` 都是对应完整权重在 validation 网格上的最高点。

当 `lambda=1`、完全丢弃主模型排序时，三个数据集的 validation 目标值均显著下降。这证明规则教师应作为主模型的互补信号，而不是独立替代主模型。

三个数据集的最优规则强度不同，也再次支持数据集专属校准：

- NYC 可以接受较强的规则干预。
- CA 需要中等强度。
- TKY 只需要较弱的用户偏好修正。

## 7. 当前结论

本次消融支持以下结论：

1. NYC 的主要提升来自用户偏好、空间与时间规则的协同。
2. CA 的头部排序主要依赖时间和用户偏好，空间规则更偏向 Recall@5 与 Recall@10。
3. TKY 只需要用户偏好，数据集自适应权重避免了无效时空规则造成退化。
4. 类别转移和热度在 NYC、CA 中权重很低，当前证据不足以证明它们带来稳定增益。
5. 规则教师不能替代主模型；受限的融合强度是必要设计。

当前仍是单次候选导出和单 checkpoint 结果，不作统计显著性声明。CA、TKY 的最终 MoE 规则消融仍标记为 `[NEEDS DATA]`。
