# NYC：Jev 类别预测辅助 A4 排序

日期：2026-09-20。重复使用 NYC 开发数据的探索性实验，不是独立确认性结论。

## 设计

不加规则门控。Jev 只预测下一站的场所类别；A4 保留同类别内部 POI 排序。输入为已知查询时间、最近12条严格历史及候选中出现的类别；类别元数据仅取自训练集。目标类别仅用于本地评估，不进入请求。

`P_c = sum(p_A4_i in category c)`；`r_i = q_Jev_c * p_A4_i / P_c`；`p_final = (1-alpha)*p_A4 + alpha*r`。候选集合不变。
Jev alpha=0.35；均匀类别对照 alpha=0.01。两者均只在 selection 上按同一网格独立选参。
