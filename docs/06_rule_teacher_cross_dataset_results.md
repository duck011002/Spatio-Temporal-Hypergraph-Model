# 数据集自适应规则教师首轮结果

## 1. 实验范围

本文归档显式规则教师的首轮实验结果。规则教师只重排主模型已经生成的 Top-20 候选，不增加或删除候选，不接入 LLM，也不重新训练主模型。

三组实验的骨干并不完全相同：

- NYC 使用已冻结的 A4，即 12 专家、6 个自适应二元组、跨组 Top-2、无辅助损失动态偏置和样本自适应双门控残差。
- CA 与 TKY 为节省计算，使用已有 R0 checkpoint 对规则教师进行跨数据集预验证。

因此，NYC 可以用于判断 A4 与规则教师是否互补；CA、TKY 当前只能用于判断共享规则骨架能否通过数据集专属统计和权重获得正向结果。三数据集最终 MoE 与规则教师联合结果标记为 `[NEEDS DATA]`。

所有权重只在各数据集自己的 validation 上搜索，test 不参与权重选择。当前均为单次 checkpoint、单次候选导出结果，不作统计显著性声明。

## 2. 规则与选择目标

共享规则包括：

1. 空间可达性。
2. 时间匹配。
3. 类别转移。
4. 用户偏好。
5. POI 热度。

每个数据集分别拟合训练集统计、规则权重与总规则强度。validation 的固定选择目标为：

```text
4 * Recall@1 + Recall@5 + MRR + NDCG@5
```

最终融合为：

```text
final_score = (1 - lambda) * model_score
              + lambda * sum(rule_weight[k] * rule_score[k])
```

## 4. 数据集专属权重

| 数据集与骨干 | lambda | 空间 | 时间 | 类别转移 | 用户偏好 | POI 热度 |
|---|---:|---:|---:|---:|---:|---:|
| NYC A4 | 0.50 | 0.3098618 | 0.2980200 | 0.0208300 | 0.3597163 | 0.0115719 |
| CA R0 | 0.25 | 0.2677480 | 0.3411751 | 0.0180008 | 0.3701533 | 0.0029229 |
| TKY R0 | 0.20 | 0.0000000 | 0.0000000 | 0.0000000 | 1.0000000 | 0.0000000 |

观察：

- NYC 接受最强的规则干预，`lambda=0.50`，且用户偏好、空间和时间三项权重接近。
- CA 的三项主要规则构成与 NYC 相似，但总规则强度只有 0.25。
- TKY 的 validation 选择了纯用户偏好，空间、时间、类别转移与热度权重均为 0，总规则强度为 0.20。

解释：

- 三个数据集不适合共享固定规则权重。
- NYC 的 A4 候选覆盖较强而首位排序偏弱，规则教师与其互补，因此提升最大。
- TKY 数据更密集，原模型可能已经吸收较多时空规律；本轮显式规则中只有用户长期偏好提供了额外信号。这是基于当前结果的解释，仍需规则消融验证。
- CA 的地理覆盖虽然更广，但本实现的空间尺度统计限定在同一轨迹内，因此不能用全数据集覆盖范围直接推断其距离衰减尺度。

## 5. Validation 一致性

三组 validation 的选择目标均提高，且 Recall@20 保持不变。

- NYC：Recall@1 从 0.2614285714 提高到 0.2707142857，Recall@5 从 0.5050000000 提高到 0.5264285714，MRR 从 0.3724432537 提高到 0.3817571201。
- CA：Recall@1 从 0.2017568716 提高到 0.2054406347，Recall@5 从 0.3768773024 提高到 0.3845281950，MRR 从 0.2850745497 提高到 0.2905169847。
- TKY：Recall@1 从 0.2265579499 提高到 0.2297612114，Recall@5 从 0.4453989517 提高到 0.4499126383，MRR 从 0.3279353167 提高到 0.3313782955。TKY validation 的 Recall@10 从 0.5345078626 小幅下降到 0.5333430402，应作为当前选择目标偏重头部排序的限制如实保留。

validation 与 test 在主要头部指标上方向一致，支持规则教师的正向结果不是只出现在 test 上。当前证据仍不足以声明统计显著性。

## 6. 与已归档 A4 的口径差异

本轮规则教师导出的 NYC 配对 A4 基线为：

- Recall@1：0.2613214551。
- Recall@5：0.5263548627。
- Recall@10：0.6117297699。
- Recall@20：0.6763177431。

先前 A4 正式训练结束后立即执行的 test 为 0.2613214552、0.5270972252、0.6132145524、0.6785449386。Recall@1 相同，Recall@5、Recall@10、Recall@20 分别相差 1、2、3 个样本。

原因是现有 `NeighborSampler` 在推理时仍执行随机邻居采样。训练结束后的正式 test 与独立加载 checkpoint 后重新导出候选所处的随机数状态不同。规则教师的效果必须使用本轮同一次候选导出的配对原始排序进行比较；不能把规则教师结果与另一次随机采样的 A4 结果直接作严格配对差值。

候选缓存已经冻结，后续规则诊断可通过 `--reuse-candidates` 完成，不再重新采样。

## 8. 当前结论与边界

可以声明：

- 在当前单次候选导出上，显式规则教师在 NYC A4、CA R0 与 TKY R0 上都提高了 Recall@1、Recall@5、Recall@10、MRR 和 NDCG@5，同时保持 Recall@20 不变。
- 三个数据集通过相同搜索流程得到不同的规则强度与权重，支持数据集专属校准的必要性。
- NYC A4 与规则教师表现出明显互补性。

不可以声明：

- 当前结果具有统计显著性。
- CA、TKY 已经验证完整的 MoE 与规则教师联合模型。
- TKY 的空间和时间规律本身无效；当前只能说明它们未在本轮候选与选择目标下提供额外收益。
