# 离线补充分析方案（2026-09-21）

本文件在本轮补充分析运行前写入。已有 test 数字已被研究者看过，因此下列分析均为事后补充分析，不称预注册或独立确认性实验。冻结已有 A4 checkpoint、Top-20 候选、Jev 响应和最终参数；不据补充分析修改主模型，不新增 API 请求。

1. 主结果：从相同候选复算 R@1/5/10/20、NDCG@1/5/10/20、MRR；验证来源哈希、标签对齐、完整样本覆盖、原报告数值一致。
2. 不确定性：按用户聚类重采样 2000 次，seed=20260921，为全部主指标的配对差给出描述性 95% CI。重复抽样不是多随机种子训练；不以这些 CI 代替多种子均值/标准差。
3. 固定参数消融：lambda=0；uniform-category；候选内 Jev 概率随机置换（seed 0..4 全部报告）；去掉类别质量校正；去掉 smoothing；T=1；lambda=1 的类别质量替换。所有变体使用原参数，其余不重调，验证与测试均完整报告；不选择 test 最优变体。
4. 固定类别先验对照：以训练事件全局类别频率、训练事件用户类别频率替换 Jev，保持融合公式与已冻结参数。该对照隔离语义输入来源，不声称是最优调参基线。
5. 同候选规则教师：训练事件生成规则特征；只在 validation 的 selection 用户分区搜索 256 组 Dirichlet 权重、均匀权重与五个 one-hot 权重，lambda=0..1 步长 .05，seed=20260723，目标 R@1+.25*MRR，同分选小 lambda。按固定规则选出一个配置，保存后才读 test；报告 calibration/audit 而不隐藏未通过者。不同搜索空间意味着不是严格等预算对比。
6. 分组：训练用户频次四分位阈值划分稀疏程度（不是零历史冷启动）；候选类别数 1/2–4/5–9/10–20；历史 POI 是否曾出现在该用户训练记录；这些桶只作描述分析。
7. 概率诊断：按训练类别映射得到真实类别，未出现在候选类别时标 outside；类别 accuracy、Brier、NLL、10 个等宽 confidence bin 的 ECE。Jev 返回概率需有限、非负、和接近 1，异常时拒绝计算。校准误差不能证明 Jev 内部训练校准，更不能证明优于其他 LLM。
8. 误差案例：按原查询顺序各取最早三个 rescued 与 lost，报告类别和前后名次，不挑最漂亮的例子，不公开用户身份或原始轨迹。
9. 效率：从原 ledger 统计成功请求、重试、usage、延迟 p50/p95 与按历史单价的估算费用；每 attempt 只计最终事件，避免 reserved/success 双计。计费估计不是账单；API 服务时间不能作为 GPU 训练时间。

本轮无需 GPU；结构消融、多训练种子、Top-50/100 扩候选与其他外部模型对照单独列待办，不能用缓存重排替代。
