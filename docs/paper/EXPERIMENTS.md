## 2. 数据与评估协议

数据统计见 [完整表](generated/dataset_statistics.md)。NYC/CA/TKY 的 test 查询数分别为1347/2780/**7038**；TKY 的6868是 validation，不是test。仅末位置评估、时间划分和滚动可见历史遵循当前实现。训练事件数不同于末位置查询数，不拿两者直接计算 train/val/test 比例。

主干仅使用允许的历史信息，Jev 输入最近12条历史及已知查询时间特征，不含目标POI/类别。类别映射从训练记录构建。滚动评估中允许查询之前已经发生的验证/测试事件作为历史；如果比较方法采用固定历史，则需先统一协议。类别元数据可见性、未见 POI 映射与候选范围需要在最终论文明确。

NYC：原 audit 未过后，经明确授权执行固定配置 test；CA：原 selection 方案；TKY：原 calibration 未过后采用修订的 calibration-safe 方案。不得将三个数据集包装成完全相同的选择流程，或声称这是从未查看测试集的预注册评估。以后冻结统一流程，多种子验证不能消除既有研究者选择历史，应在局限中说明。

## 3. 指标

对每个查询唯一正确 next POI 的完整排名 r：Recall@K=1[r≤K]；NDCG@K=1[r≤K]/log2(r+1)；MRR=1/r，均对查询取平均。单目标时 Recall@K 与 Hit@K 等价，NDCG@1=Recall@1。报告 K=1/5/10/20；NDCG 无需重训练，现已从保存排名复算。

本项目在原 Top20 集内重排，故 Recall@20 **数学上必然不变**，不是漏跑。NDCG@20仍能改善。Top20外的正确标签保留其原主干rank以计算完整MRR；不能将不在候选中的rank一律设21。

## 5. 模型结构与历史对照

[NYC演进表](generated/historical_nyc.md)保留 R1/R1.1/R1.2/A1/A2/A3/A4/B-Tanh。A3 的训练日志 R@1=.273200，高于A4的.261321；B-Tanh的MRR=.378212，低于A4的.379708。不能选择性忽略这些事实，也不能把“最终保留A4”当作它在所有指标最优的证据。

这些版本涉及专家数量、分组、平衡方式和门控等联合变化，定位为开发对照。原始 STHGCN R0 与 A4 的严格同协议多种子比较、参数量匹配、移除 shared/group/context/bias 的单因素实验尚待GPU。仓库上游 README 的文献结果和多种子统计不属于本项目新增实验。

## 6. 概率融合机制消融

[完整消融表](generated/fusion_ablations.md)及JSON保存全部五个 shuffle seed，不择优。固定主方案 λ/T，不为每个变体重新优化；所以是固定操作点敏感性，不代表各替代方法的最优性能。

已观察到：均匀类别先验总体弱于完整方案；打乱语义概率在NYC/CA伤害明显，在TKY @1影响较弱；直接类别质量替换（λ=1）明显伤害性能；CA/TKY 去掉 smoothing 会下降。这支持保留主干排序信号而非完全交给语义分类器。

必须保留的反证：去掉类别质量校正在 NYC、CA 的 R1/R5/R10/NDCG10/MRR 全部优于完整方案；TKY将T改为1也优于冻结的T2测试结果。当前数据不能证明质量校正普遍必要或当前参数全局最优。**不根据这些已见 test 结果换主方案**；下一轮先在验证集限定候选公式，再做新种子/新划分确认。NYC去smoothing提高R1却降低MRR，也说明只看单一指标会误导。

## 7. 与规则教师的比较

[同候选规则对照](generated/rule_comparison.md)只用 selection 分区搜索权重和强度；不同搜索预算，不称严格等预算比较。所有 calibration/audit 分区结果同样保存在JSON，未用是否通过来隐藏不利结果。

Jev在NYC的R1/MRR强于规则，但规则的R5/R10更高；CA两者R1/MRR接近，规则R10/NDCG10更高；TKY Jev在表中五项指标均略高。合适的结论是“概率语义信号与规则各有侧重”，不是“可靠性全面超过已有教师”。需要后续配对多种子和同预算验证。

## 8. 分组、概率可靠性与案例

每数据集JSON包含 `stratified`、`cases`、`probability_diagnostics`：训练频次四分位、候选类别数、训练已见/未见用户POI，以及按查询原顺序取前三个纠正/损失案例。未输出原始用户轨迹。分组结果需连同样本量阅读，禁止仅挑增益最大的一组。

当前类别 ECE（10等宽置信度桶）：NYC .2433、CA .3303、TKY .2537；类别accuracy分别 .3415/.2424/.4422。概率并非天然良好校准，不能仅因API返回概率就称为“可靠概率仲裁”。类别集合大小不同，跨数据集的Brier/NLL也不能脱离任务难度直接比较。概率可靠性与推荐收益不是同一命题。
