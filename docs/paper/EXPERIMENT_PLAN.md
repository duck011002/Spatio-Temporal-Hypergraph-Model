# 补实验清单：先主实验，再解释机制

本文件是计划，不是已完成的结果。本轮不启动GPU训练或付费API。

## P0：主实验与统一协议（最优先）

1. 固定数据/评估协议、查询名单、候选空间和主指标：R@1/5/10/20、NDCG@1/5/10/20、MRR；保存划分、配置、源码哈希。统一validation选择规则并披露旧策略变化。选择目标不能随 test 表现改变。
2. 三数据集同seed重跑/核对原STHGCN（R0）与A4，再对各自候选分别加同协议Jev：R0、A4、R0+Jev、A4+Jev四条件。这样能区分结构收益、语义收益及相互作用。
3. 优先3个训练seed，正式建议5个配对seed。全部报告均值±标准差；同seed同数据、同评估配置；按预定seed列表运行而不是只保存好结果。既有每数据集A4单seed可作为开发结果，但若协议有改动不能直接混入新均值。
4. 基线覆盖简单频次/个性化频次、序列、时空注意力、图/超图、近期next-POI方法。建议6–8种有代表性的强基线，先核实开源与可适配性再锁定名单；至少包含原STHGCN、同候选规则教师、参数量匹配的非MoE适配器。近期KAIS方法是调查候选，不直接搬论文数字。
5. 同时导出 full-label rank、Top100候选/分数、查询索引和类别映射，以后K=10/20/50/100可离线分析。现有Top20无法凭空重算Top50。API请求按真实请求哈希复用，候选/提示变了才新增；不重复已有请求。
6. 先validation再锁定参数/模型，最后一次完整test，结果写入不可覆盖的目录。统计主比较优先A4+Jev vs A4；其余多比较预先指定并做校正，bootstrap单独标明不是训练方差。

## P1：A4 单因素结构消融（GPU）

| 变体 | 固定/改变 | 回答问题 |
| --- | --- | --- |
| 无shared expert | routed数量与rank保持不变；另报参数量 | 共享路径必要性 |
| 无分组top2 | 同12专家、rank32，全球top2 | 分组选择贡献 |
| 随机固定配对 | 同6组及每组大小；多配对seed | 学到的分组是否胜过任意分组 |
| 无bias平衡 | 仅关bias更新，其余固定 | 负载控制贡献 |
| 固定shared gate | 固定为预先验证选择的常数 | 自适应共享权重贡献 |
| 固定residual gate | 固定常数、同残差路径 | 当前近饱和门控是否必要 |
| 无hypergraph router context | 专家与主干不变，仅router输入改变 | 条件路由信息贡献 |
| 参数匹配dense adapter | 近似相同新增参数/训练预算 | 是否只是参数增加 |

先每变体三数据集单seed定位实现问题，再优先对贡献核心补3–5seed；不能把定位阶段当最终显著性证据。共享/残差gate、路由熵、每专家流量、组内相似度、负载CV与推荐指标一起记录。

## P2：Jev 与融合（CPU/API为主）

已完成固定参数13变体、规则/先验对照、聚类CI、分组、概率诊断和案例。下一步：

- 将有/无类别质量校正作为**待验证**公式，用validation统一选择，测试不调参。保留当前反证，不能直接改写历史最优。
- validation λ/T/epsilon敏感性曲线，并报告selection/calibration/audit差异；当前未生成完整网格敏感性图。
- 提示移除history/time、历史长度0/4/8/12/20、选项顺序/语义标签扰动。调用需要新API响应，不能由已有缓存伪造。
- 至少一个通用LLM约束分类/概率对照；输出概率定义必须可比，不能用任意自报confidence当校准概率。记录model/version/提示/token/费用/错误率，相同信息和预算。
- 固定100–200条预定抽样查询重复调用，量化选项顺序和请求稳定性；API失败、超时、无效概率以及回退单独报告。先征求调用预算/服务选择，当前不执行。
- TopK变化、候选oracle上限、类别oracle上限；oracle只能标上界，不能作为可部署方法。K>20先GPU导出。

## P3：完整性与适用范围

长尾/活跃用户、重复vs新地点已做描述分组；还需受控历史缩短/训练稀疏实验（后者要训练），按时间跨度/距离分桶，实际case可视化和失败原因编码。仅训练低频用户不叫真正冷启动。若声称跨城市泛化，必须增加跨域训练/测试，不可由三城市分别训练推断。

效率统一测同硬件同batch的train wall time、推理吞吐、p50/p95延迟、峰值GPU显存、参数量、API额外开销。训练损失、验证曲线、早停点、所有失败run与种子需保留。

## 排期参考（非承诺）

实测单次A4三个数据集合计约8.43小时；新增2组完整seed约16.85小时，新增4组约33.71小时，仅A4训练，不含基线/结构变体/API。R0和外部基线必须先小规模测速，不假定与A4等时。每新增一个三数据集A4量级结构变体约再增加8.43小时，8个变体单seed粗估67.4小时；实际早停/硬件竞争会改变时间。

建议分批：P0同协议主干与主方案 → 强基线 → P1核心移除 → 其余敏感性和效率。不为了完成所有组合一次开大矩阵。每批先smoke成功，再后台队列、断点、日志和30分钟检查；OOM/非有限值先保留证据，再安全修复。

## 投稿前验收

主表统一协议、至少3个且优先5个seed；近期强基线与公平调参；核心结构单因素消融；至少一种通用模型概率对照；完整负结果；重算脚本与环境；数据/API伦理与使用权说明。此清单是本研究充分性目标，不是KAIS保证接收标准。
