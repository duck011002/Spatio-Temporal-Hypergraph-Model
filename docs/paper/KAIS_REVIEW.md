# KAIS 实验对标与投稿准备

核查日期：2026-09-21。目标是 Knowledge and Information Systems，非同名会议。以下区分官方要求、公开论文实例、我们自己的建议；期刊没有在所查指南中规定统一的实验数量门槛。

## 官方要求

[投稿指南](https://link.springer.com/journal/10115/submission-guidelines)要求原创研究提供 Data Availability Statement；说明支持结果的数据如何获取及限制。建议准备 LaTeX 可编辑源文件和编译 PDF；Word 也接受。实验方法中的 LLM 使用需要适当说明。补充材料须在正文引用并提供说明，上传版本应可直接发表。投稿前还需确认作者、贡献、利益冲突、资助和数据使用权限，不能由本项目自动代填。

## 已核实的实例

| 论文 | 可核实实验范围 | 对我们的启示 |
| --- | --- | --- |
| [ISTMM，next-POI，2026](https://link.springer.com/article/10.1007/s10115-025-02646-5) | 摘要明确四个真实数据集；订阅预览未提供足够完整的消融细节 | 三数据集不自动构成不足，但需解释覆盖范围，不能声称已逐项复刻该文实验体系 |
| [UPLM，next-POI](https://link.springer.com/article/10.1007/s10115-025-02378-6) | 摘要列 NYC、Weeplace 两数据集，提供代码线索；未据预览断言种子数量 | 数据集个数不是唯一充分性标准；优先可复现、同协议的强基线 |
| [HRRPE，2025，全文开放](https://link.springer.com/article/10.1007/s10115-024-02331-z) | 两数据集、七种基线、参数分析、冷启动分析、三组件移除、统计分析 | 主表之外需要组件必要性、适用人群、参数稳定性与统计证据；不机械照搬其检验方法 |
| [HyHG，2026，全文开放](https://link.springer.com/article/10.1007/s10115-026-02785-3) | 三领域时间超图、按时间划分、多个基线家族、组件消融和案例分析 | 明确时间边界，覆盖基线家族，将机制与案例相连接；讨论鲁棒性不等于完成扰动实验 |

近期同刊 [SeekNew](https://link.springer.com/article/10.1007/s10115-026-02788-0)可列入后续相关工作/基线可复现性调查，尚未将其数字或实现当作已验证事实。不同数据清洗、划分和候选空间下的文献数字不能直接填进我们的比较表。

## 对本项目的判断

目前足以写出“可核验的初步实验章节”，还不足以宣称达到完整投稿证据标准。关键缺口不是表格数量，而是：统一协议强基线、多训练种子、A4 单因素结构消融、概率模型替代对照，以及对 NYC/TKY 策略调整的透明解释。

建议正文保持约 6–8 组核心表/图：数据与设置、主结果、结构消融、概率融合消融、敏感性、分组表现、效率、误差机制。附录承载完整种子、提示模板、所有变体、负结果、API 版本/失败处理、数据与代码清单。此数量是本项目规划，不是 KAIS 的硬性要求，也不保证录用。
